Map of alternative fuel stations across United States and Canada. Built with the ArcGIS Maps SDK for JavaScript with live data pulled from ArcGIS Living Atlas.



\- Live public dataset from ArcGIS Living Atlas (Alternative Fuel Stations, US DOE)

\- Stations color-coded by fuel type (Electric, Hydrogen, CNG, Biodiesel, and more) using a unique-value renderer, so infrastructure types are visually distinguishable at a glance

\- Interactive sidebar with checkboxes to toggle individual fuel types on and off, letting users filter the map to only the categories they want to see

\- Click any station for details: fuel type, city, and current status





Built with;

\- ArcGIS Maps SDK for JavaScript

\- HTML, CSS, JavaScript







Data source

Alternative Fuel Stations dataset, ArcGIS Living Atlas of the World (Esri / U.S. Department of Energy)
